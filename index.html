Frequently asked questions

What is responsive web design?

One website whose layout adapts to any screen size, so it is easy to read and use on phones, tablets and desktops.

How long does a project take?

Typically 3 to 8 weeks depending on pages, features and content.

Will a redesign hurt my Google rankings?

Not when URLs and metadata are planned properly.

Do you support the site after launch?

Yes, with hosting, maintenance and security plans.
